# Layout_Liner_Management

공장이나 건물의 평면도 위에서 공간 레이아웃을 그리고 설계하는 웹 기반 경량 2D CAD 툴입니다.
설치 없이 브라우저에서 실행되며, 2D CAD 구속·측정·스냅 기능을 단계적으로 갖춰 나갑니다.

## 현재 기능

### 1단계: 기반

- 화면 이동(가운데 버튼 드래그 또는 Space+드래그), 커서 기준 휠 확대·축소, 전체 보기(F)
- 1-2-5 단계로 자동 조정되는 그리드와 그리드 스냅(F9)
- 그리기 도구: 연속 선(L, 시작점 클릭 시 닫힘), 사각형(R), 원(C)
- 선택(V): 클릭, Shift+클릭, 영역 선택(왼→오른쪽: 완전 포함, 오른→왼쪽: 걸침), 드래그 이동, Delete 삭제
- 연결된 선은 꼭짓점을 공유하므로 한 변을 옮기면 이웃 변이 함께 따라옵니다
- 실행 취소/다시 실행(Ctrl+Z, Ctrl+Y 또는 Ctrl+Shift+Z)
- JSON 파일 저장(Ctrl+S)·열기(Ctrl+O), 브라우저 자동 저장
- 그리는 중 길이·각도·크기 실시간 표시, 표시 단위 mm/m 전환

### 2단계: 스냅·측정
- 객체 스냅(F3): 끝점, 교차점, 중심, 중점, 사분점, 수직 발 — 종류별 마커와 이름 표시
- 각도 추적(F10): 기준점에서 15° 단위로 안내선, Shift로 수평/수직 고정, 그리드가 켜져 있으면 거리도 그리드 단위로 맞춤
- 기존 끝점을 클릭하면 새 점을 만들지 않고 연결(공유 꼭짓점), 이동 시 잡은 점이 다른 형상에 스냅
- 측정: 거리(M, ΔX·ΔY·각도 포함), 각도(N), 면적·둘레(A, m²)
- 치수(D): 정렬 치수. 형상의 끝점에 붙이면 형상을 움직일 때 값이 따라 갱신되고, 치수만 끌면 치수선 위치만 이동

### 3단계: 구속
- 구속 버튼: 수평, 수직(선 여러 개), 평행, 직각, 동일(선 2개는 길이, 원 2개는 반지름), 고정(선택한 형상의 점), 해제
- 치수를 더블클릭해 값을 입력하면 구동 치수(빨간색)가 되어 형상이 그 길이로 맞춰지고, 비워 두면 참조 치수로 돌아갑니다. 원을 더블클릭하면 반지름을 지정합니다
- 구속된 형상을 끌면 구속을 지키며 따라오고, 구속 때문에 정확히 따라갈 수 없으면 허용되는 방향으로만 움직입니다
- 충돌·중복되거나 형상을 0 길이로 무너뜨리는 구속은 적용하지 않고 이유를 알려 줍니다
- 상태 표시줄에 남은 자유도를 보여 주고, 완전히 구속된 형상은 초록색으로 그립니다
- 솔버는 [planegcs](https://github.com/Salusoft89/planegcs)(FreeCAD 스케치 솔버의 WebAssembly 빌드, LGPL)이며, 구속을 처음 쓸 때만 내려받습니다(약 480 KB)

### 4단계: 레이아웃
- 레이어 패널: 레이어 추가·삭제(빈 레이어만), 이름(더블클릭)·색 변경, 표시·잠금, 현재 레이어 지정. 새로 그리는 객체는 현재 레이어에 들어가고, `선택 → 현재 레이어`로 옮길 수 있습니다
- 설비(블록): 설비 종류(이름, 폭×깊이, 번호 접두어)를 라이브러리로 관리하고, 목록에서 고르거나 E 키로 배치합니다. 배치 중 R로 90° 회전하며, 종류의 크기를 바꾸면 배치된 설비가 모두 따라 바뀝니다
- 설비마다 번호(예: MC-1)가 자동으로 붙고, 설비를 더블클릭해 바꿀 수 있습니다. 설비 외곽의 모서리·변 중점·중심에 스냅되며, 몸체 안쪽을 클릭해도 선택됩니다
- 90° 회전: 설비만 선택하면 제자리에서, 그 밖에는 선택 영역 중심을 기준으로 돌립니다(구속된 객체는 제외)
- 배열 복사: 열 수, 행 수, 간격을 입력해 선택을 격자로 복사합니다. 공유 꼭짓점과 선택 안의 구속도 함께 복사되고, 설비 번호는 새로 매겨집니다
- 설비 목록 CSV: 번호, 설비명, 크기, 위치, 회전, 레이어를 엑셀에서 바로 열 수 있는 CSV(UTF-8 BOM)로 저장합니다

### 5단계: 입출력 확장
- DXF 가져오기: `열기`에서 .dxf를 고르면 현재 도면에 더해집니다(한 번에 실행 취소 가능). 선, 폴리선(호 구간 포함), 원, 호, 블록 참조(회전·축척·배열)를 읽고, 레이어 이름·색·표시·잠금을 가져옵니다. 호는 10° 이하의 직선 조각으로 바뀌고, 맞닿은 끝점은 공유 꼭짓점이 됩니다. 단위는 `$INSUNITS`([코드표](https://ezdxf.mozman.at/docs/concepts/units.html))에서 읽고, 없으면 물어봅니다. 문자·해치·치수 엔티티는 건너뛰고 개수를 알려 줍니다
- DXF 내보내기: AutoCAD 등에서 열 수 있는 ASCII DXF R12(mm)로 저장합니다. 설비는 닫힌 폴리선과 번호 문자로, 치수는 선과 값 문자로 바뀝니다
- 밑그림: PNG/JPG 평면도를 불러와 투명도를 조절하고, `축척·위치 맞추기`로 실제 거리를 아는 두 점을 클릭해 축척을 맞춘 뒤 기준점을 원하는 위치로 옮깁니다. 이미지는 도면 파일에 함께 저장됩니다(8 MB 이하)
- SVG 내보내기와 인쇄: 보이는 레이어를 mm 단위 SVG로 저장하거나, 한 장에 맞춰 인쇄합니다. 인쇄 창에서 PDF로 저장할 수 있습니다

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 단위 테스트
npm run build    # 배포용 빌드 (dist/)
```

### Docker로 서버에 배포

`main`에 병합될 때마다 `ghcr.io/loborover/layout-liner-management:latest` 이미지가 자동으로 만들어집니다. 서버에는 [`deploy/docker-compose.yml`](deploy/docker-compose.yml)만 두고 `docker compose pull && docker compose up -d`로 설치·업데이트합니다. 처음 설정할 항목과 자세한 사용법은 [deploy/README.md](deploy/README.md)를 참고하십시오.

## 구조

| 경로 | 역할 |
| --- | --- |
| `src/model/` | 문서 모델(점·엔티티·레이어·설비 종류), 명령/실행 취소, 배열 복사·회전, 선택, R-tree 공간 인덱스 |
| `src/view/` | 뷰포트 좌표 변환, Canvas 2D 렌더러, 표시 형식 |
| `src/tools/` | 선택·선·사각형·원·치수·설비 배치·밑그림 맞추기 도구, 측정 도구 |
| `src/constraints/` | planegcs 연동, 구속 묶음 계산, 구속 추가·드래그 서비스 |
| `src/snap/` | 객체 스냅·각도 추적·그리드 스냅 엔진 |
| `src/io/` | 도면 파일(JSON) 직렬화와 검증, DXF 읽기·쓰기, SVG, 설비 목록 CSV |
| `src/ui/` | 레이어·설비 패널 |
| `src/geom/` | 벡터, 교차점, 다각형 면적, 치수 기하 |

좌표는 mm 단위이며 Y축이 위쪽을 향합니다. 모든 편집은 명령(`src/model/commands.ts`)으로 기록되어 실행 취소가 가능합니다.
