# Layout_Liner_Management

공장이나 건물의 평면도 위에서 공간 레이아웃을 그리고 설계하는 웹 기반 경량 2D CAD 툴입니다.
설치 없이 브라우저에서 실행되며, 2D CAD 구속·측정·스냅 기능을 단계적으로 갖춰 나갑니다.

## 현재 기능 (1단계: 기반)

- 화면 이동(가운데 버튼 드래그 또는 Space+드래그), 커서 기준 휠 확대·축소, 전체 보기(F)
- 1-2-5 단계로 자동 조정되는 그리드와 그리드 스냅(F9)
- 그리기 도구: 연속 선(L, 시작점 클릭 시 닫힘), 사각형(R), 원(C)
- 선택(V): 클릭, Shift+클릭, 영역 선택(왼→오른쪽: 완전 포함, 오른→왼쪽: 걸침), 드래그 이동, Delete 삭제
- 연결된 선은 꼭짓점을 공유하므로 한 변을 옮기면 이웃 변이 함께 따라옵니다
- 실행 취소/다시 실행(Ctrl+Z, Ctrl+Y 또는 Ctrl+Shift+Z)
- JSON 파일 저장(Ctrl+S)·열기(Ctrl+O), 브라우저 자동 저장
- 그리는 중 길이·각도·크기 실시간 표시, 표시 단위 mm/m 전환

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 단위 테스트
npm run build    # 배포용 빌드 (dist/)
```

## 구조

| 경로 | 역할 |
| --- | --- |
| `src/model/` | 문서 모델(점·엔티티·레이어), 명령/실행 취소, 선택, R-tree 공간 인덱스 |
| `src/view/` | 뷰포트 좌표 변환, Canvas 2D 렌더러, 표시 형식 |
| `src/tools/` | 선택·선·사각형·원 도구 |
| `src/io/` | 도면 파일(JSON) 직렬화와 검증 |
| `src/geom/` | 벡터·교차 등 기본 기하 |

좌표는 mm 단위이며 Y축이 위쪽을 향합니다. 모든 편집은 명령(`src/model/commands.ts`)으로 기록되어 실행 취소가 가능합니다.

## 로드맵

1. 기반 (현재)
2. 스냅·측정: 끝점·중점·교차점·수직 발 스냅, 거리·각도·면적 측정, 치수선
3. 구속: [planegcs](https://github.com/Salusoft89/planegcs) (FreeCAD 솔버 WASM) 연동
4. 레이아웃: 설비 블록, 레이어, 배열 복사, 설비 목록 내보내기
5. 입출력 확장: DXF, 밑그림 이미지, PDF/SVG
